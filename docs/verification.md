來源驗證是當時的真實結果，不保證外部服務之後永遠可用。TPEx 在驗證使用的 Windows 環境須啟用 Node 的 `--use-system-ca`，程式仍驗證 TLS 憑證。整合驗證曾遇兩次 TPEx socket 中斷，兩次皆記錄失敗並完成清理；後續完整驗證成功。相同 GET 的傳輸中斷最多立即重試一次且間隔至少 3 秒；HTTP 拒絕與 TLS 失敗不以此方式重試。
